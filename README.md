# Birthday XP - Hidden Object Edition 🎂

Struktur folder project sudah dirapikan dengan 7 party items (termasuk app **Gacha** berhadiah boneka kucing oren **Simba** pada tarikan ke-5):

```text
birthday-xp/
├── index.html                          # Struktur utama halaman
├── README.md                           # Panduan penempatan aset
├── css/
│   └── style.css                       # Tampilan tema Windows XP Luna
├── js/
│   ├── config.js                       # Pengaturan PIN, pesan, gacha & path aset
│   └── app.js                          # Logika hidden objects (7 item), gacha, slideshow & audio
└── assets/
    ├── audio/
    │   └── (taruh lagu.mp3 di sini)
    └── images/
        ├── wallpaper/
        │   └── (taruh wallpaper.jpg di sini)
        └── photos/
            └── (taruh foto1.jpg sampai foto10.jpg di sini)
```

## Daftar 7 Party Items
1. 🎈 **Balloon** — di dalam folder `My Documents`
2. 🎁 **Gift** — tersembunyi di belakang jendela `Readme.txt`
3. 🕯️ **Candle** — di dalam `Recycle Bin`
4. 📼 **Cassette** — klik tombol `Grab Tape` di `Media Player`
5. 🎞️ **Film Roll** — di slide foto ke-10 pada `My Pictures`
6. 🐈 **Simba (Boneka Kucing Oren)** — tarik 5 kali di aplikasi `Gacha`
7. 🔑 **Golden Key** — buka `Secret_Vault.exe` dengan PIN `2612`
